P2PK Explorer

Pay-to-Public-Key was Bitcoin's original way to lock coins — straight to a raw public key, with no address. Ordinary explorers can't find these (there's no address to search), so they stay hidden. This is the explorer for them: the actual public keys, decoded, starting with the coins Satoshi mined.

How to read it. A P2PK output is literally <public key> OP_CHECKSIG. Whoever holds the matching private key can spend it by signing — no address, no hashing. The very first Bitcoin transaction (Satoshi → Hal Finney, block 170) was P2PK, and nearly every early coinbase was too. Search by txid, public key, or block below.

The public API returns P2PK when you ask by txid — that's how this works without a special index.
