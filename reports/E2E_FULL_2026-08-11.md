### Why the earlier test missed the OP_RETURN bug

The earlier run tested the **engine** (it called the send/sweep functions directly with correct arguments), so it never exercised the button wiring. The OP_RETURN failure was a pure **UI event bug**: the fee presets and the Pay/Message toggle shared a CSS class, so tapping "Just write a message" also fired the fee handler and wrote `undefined` into the fee field. The fix scopes the fee handler, and the new **real-DOM UI test** now covers this whole class of bug.
